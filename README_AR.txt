تطبيق تسيير تربصات الأطباء المقيمين — نسخة Android/Termux
CHU Tizi-Ouzou | مسؤول التوزيع: Pr. Y. Benhocine

ماذا تتضمن النسخة؟
- لوحة قيادة وقوائم المقيمين حسب السنة الرابعة ثم الثالثة ثم الثانية ثم الأولى.
- إضافة المقيمين، تعليم المقيم كمعيد، ترقية يدوية، وإنهاء التكوين.
- إدارة مصالح التربص (أساسي/إجباري/اختياري) وتحديد السنة الإلزامية عند الحاجة.
- أربع فترات للتوزيع السنوي: فيفري-أفريل، ماي-جويلية، أوت-أكتوبر، نوفمبر-جانفي.
- تحديد السعة لكل مصلحة ولكل فترة؛ منع تعيين المقيم مرتين في الفترة نفسها.
- تسجيل تاريخ التربصات السابقة، مع السنة والفترة والتاريخ عند توفرها.
- تعارضات تحتاج قرار البروفسور، مع تسجيل الموافقة/الرفض والسبب.
- سجل العمليات، إعداد السنة الدراسية وتغيير كلمة المرور.
- استيراد جماعي للمقيمين والتاريخ عبر CSV، وقوالب جاهزة.
- قاعدة بيانات محلية على الهاتف؛ لا تحتاج اتصالاً بالإنترنت أثناء التشغيل.

التثبيت في Termux (أول تشغيل):
1) فك ضغط الملف rotation_app_mobile.zip في مجلد مستقل اسمه rotation_app_mobile.
2) افتح Termux ونفّذ:
   pkg update
   pkg install python unzip
   cd ~/storage/downloads
   unzip rotation_app_mobile.zip -d ~/
   cd ~/rotation_app_mobile
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python app.py
3) افتح Chrome في الهاتف واكتب: http://127.0.0.1:5000
4) إذا كانت قاعدة البيانات جديدة ولا تحتوي على كلمة مرور، ستطلب صفحة الدخول إنشاء كلمة مرور للمسؤول (12 حرفاً على الأقل وتأكيدها).
5) إذا كانت القاعدة تحتوي على كلمة مرور قديمة، استعملها للدخول ثم غيّرها من «الإعدادات»؛ تُرقّى بصمت إلى تخزين أقوى عند نجاح الدخول. لا توجد كلمة مرور أولية ثابتة في النسخة الحالية.

التشغيل بعد ذلك:
   cd ~/rotation_app_mobile
   source .venv/bin/activate
   python app.py
ثم افتح http://127.0.0.1:5000
لإيقاف الخادم: ارجع إلى Termux واضغط Ctrl+C.

مهم جداً لحماية قاعدة البيانات القديمة:
- هذه النسخة تبدأ في مجلد مستقل بقاعدة rotation.db خاصة بها؛ لا تستبدل app.py ولا rotation.db الموجودين في ~/rotation_app.
- احتفظ دائماً بنسخة احتياطية قبل نقل البيانات.
- إذا أردت استيراد قاعدة المشروع القديم: انسخ نسخة منها فقط إلى هذا المجلد باسم legacy_rotation.db، شغّل التطبيق مرة واحدة لإنشاء القاعدة الجديدة ثم أوقفه بـ Ctrl+C، وبعدها نفّذ: python migrate_legacy.py
- سكريبت الترحيل يقرأ legacy_rotation.db فقط ولا يعدلها، ويحوّل التعيينات القديمة إلى سجل تاريخي. السنة الدراسية لبعض المقيمين لا يمكن استنتاجها من القاعدة القديمة، لذلك تُسجّل مؤقتاً في السنة الأولى ويجب مراجعتها قبل الاعتماد الرسمي.

استيراد القوائم:
- افتح «استيراد جماعي» بعد تسجيل الدخول، وحمّل القالب المناسب.
- CSV للمقيمين: الأعمدة name أو surname/firstname، year من 1 إلى 4، repeat_year (0 أو 1)، phone اختياري.
- CSV للتاريخ: resident, terrain, year_label, period, date_done.
- لا يتم حذف أي بيانات عند الاستيراد؛ السجلات المكررة للمقيمين يتم تجاوزها.
- الصور التاريخية التي وصلت من المستخدم لا تُحوّل تلقائياً إلى سجل نهائي لأن بعض الأسماء مختصرة أو غير كاملة والفترات لا تظهر دائماً. تُدخل عبر CSV أو واجهة التاريخ، مع إبقاء الأسماء كما في المصدر إلى أن تُراجع.

ملاحظة: هذه نسخة تجريبية محلية للمراجعة، وليست نظاماً طبياً معتمداً بعد. اختبرها وراجع البيانات والقواعد قبل استعمالها في توزيع رسمي. احتفظ بنسخة احتياطية دورية.


الأمان والاختبارات:
- جميع عمليات POST محمية برمز CSRF؛ لا ترسل النماذج يدوياً من دون الرمز.
- عند عدم تعيين ROTATION_SECRET يولّد التطبيق مفتاح جلسة عشوائياً عند التشغيل؛ الجلسات الحالية قد تنتهي بعد إعادة تشغيل التطبيق. للاستقرار، عيّن ROTATION_SECRET إلى قيمة عشوائية طويلة في بيئة التشغيل، ولا تحفظها في GitHub.
- ROTATION_INITIAL_PASSWORD اختياري للإعداد الآلي لأول قاعدة جديدة فقط؛ لا تضع كلمة المرور داخل الكود أو المستودع.
- لتشغيل فحوصات التطوير: source .venv/bin/activate ثم pip install -r requirements-dev.txt ثم python -m ruff check --select E9,F63,F7,F82 app.py tests ثم python -m pytest -q.
- ملف rotation.db والنسخ الاحتياطية يبقون محليين ولا يتم رفعهم إلى GitHub.
- بعد الدخول بالحساب الأول، افتح «حسابات المسؤولين» وأنشئ حسابين منفصلين: `benhocine` و`drdris`، واجعل صلاحية كل واحد «مسؤول أعلى»، وضع لكل حساب كلمة مرور قوية مستقلة. لا ترسل كلمات المرور في GitHub أو المحادثات.
- الحساب العادي بصلاحية «مستخدم» لا يمكنه تغيير الإعدادات أو مراجعة القرارات أو عرض سجل التدقيق أو تنزيل النسخة الاحتياطية.
- ملفات المقيمين تشمل مكان وتاريخ الميلاد، صورة، علامات النظري والتطبيقي لكل مقياس، وسجل التربصات والتعيينات. الصور محفوظة محلياً داخل `uploads/residents` ولا تُرفع إلى GitHub.
- النسخة الاحتياطية من زر «تنزيل النسخة الاحتياطية» أصبحت ZIP تضم قاعدة البيانات وصور المقيمين. احتفظ بالملف في مكان آمن وجرب استعادته قبل الاعتماد عليه.
- الترقية من السنوات 2–4 ونجاح DEMS تتطلب موافقة حسابي `benhocine` و`drdris` معاً؛ عند موافقة الاثنين على السنة الرابعة، يُحفظ الملف والسجل في أرشيف DEMS دون حذف المقيم أو التاريخ.
- الاستيراد الكامل من DOC/DOCX/PDF/XLS ما زال بحاجة إلى استكمال واختبارات قبل الاستعمال الرسمي.
