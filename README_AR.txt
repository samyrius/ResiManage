تطبيق تسيير تربصات الأطباء المقيمين — نسخة Android/Termux
CHU Tizi-Ouzou | مسؤول التوزيع: Pr. Y. Benhocine

ماذا تتضمن النسخة؟
- لوحة قيادة وقوائم المقيمين حسب السنة الرابعة ثم الثالثة ثم الثانية ثم الأولى.
- إضافة المقيمين، تعليم المقيم كمعيد، ترقية يدوية، وإنهاء التكوين.
- إدارة مصالح التربص (أساسي/إجباري/اختياري) وتحديد السنة الإلزامية عند الحاجة.
- أربع فترات للتوزيع السنوي: فيفري-أفريل، ماي-جويلية، أوت-أكتوبر، نوفمبر-جانفي.
- تحديد السعة لكل مصلحة ولكل فترة؛ منع تعيين المقيم مرتين في الفترة نفسها.
- تسجيل تاريخ التربصات السابقة، مع السنة والفترة والتاريخ عند توفرها.
- تعارضات تحتاج قرار البروفسور، مع تسجيل الموافقة/الرفض والسبب.
- سجل العمليات، إعداد السنة الدراسية وتغيير كلمة المرور.
- استيراد جماعي للمقيمين والتاريخ عبر CSV، وقوالب جاهزة.
- قاعدة بيانات محلية على الهاتف؛ لا تحتاج اتصالاً بالإنترنت أثناء التشغيل.

التثبيت في Termux (أول تشغيل):
1) فك ضغط الملف rotation_app_mobile.zip في مجلد مستقل اسمه rotation_app_mobile.
2) افتح Termux ونفّذ:
   pkg update
   pkg install python unzip
   cd ~/storage/downloads
   unzip rotation_app_mobile.zip -d ~/
   cd ~/rotation_app_mobile
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python app.py
3) افتح Chrome في الهاتف واكتب: http://127.0.0.1:5000
4) عند أول تشغيل، أنشئ كلمة مرور المدير الخاصة بك داخل التطبيق؛ لا توجد كلمة مرور افتراضية مشتركة.
5) احتفظ بكلمة المرور لنفسك ولا تضعها في GitHub أو داخل ملفات المشروع. أنشئ لاحقاً حساباً مستقلاً لكل مسؤول من صفحة «المستخدمون»، مع دور «Super Admin» وكلمة مرور قوية لكل حساب.

التشغيل بعد ذلك:
   cd ~/rotation_app_mobile
   source .venv/bin/activate
   python app.py
ثم افتح http://127.0.0.1:5000
لإيقاف الخادم: ارجع إلى Termux واضغط Ctrl+C.

مهم جداً لحماية قاعدة البيانات القديمة:
- هذه النسخة تبدأ في مجلد مستقل بقاعدة rotation.db خاصة بها؛ لا تستبدل app.py ولا rotation.db الموجودين في ~/rotation_app.
- احتفظ دائماً بنسخة احتياطية قبل نقل البيانات.
- إذا أردت استيراد قاعدة المشروع القديم: انسخ نسخة منها فقط إلى هذا المجلد باسم legacy_rotation.db، شغّل التطبيق مرة واحدة لإنشاء القاعدة الجديدة ثم أوقفه بـ Ctrl+C، وبعدها نفّذ: python migrate_legacy.py
- سكريبت الترحيل يقرأ legacy_rotation.db فقط ولا يعدلها، ويحوّل التعيينات القديمة إلى سجل تاريخي. السنة الدراسية لبعض المقيمين لا يمكن استنتاجها من القاعدة القديمة، لذلك تُسجّل مؤقتاً في السنة الأولى ويجب مراجعتها قبل الاعتماد الرسمي.

استيراد القوائم والتاريخ الموثق:
- افتح «استيراد جماعي» بعد تسجيل الدخول، واختر نوع الاستيراد: المقيمون أو تاريخ التربصات الموثق.
- استيراد المقيمين: الأعمدة المطلوبة surname/nom/اللقب، firstname/prénom/الاسم، year/année/السنة من 1 إلى 4؛ الهاتف ومعلومات الميلاد اختيارية.
- استيراد تاريخ التربصات: الأعمدة المطلوبة resident وterrain وyear_label (أو academic year/année universitaire)، والفترة period والتاريخ date_done اختياريان. يجب أن يكون المقيم والمصلحة موجودين مسبقاً، ويكتب اسم المقيم بصيغة «اللقب الاسم».
- يدعم الاستيراد CSV وXLS/XLSX وDOC/DOCX وPDF النصي، مع معاينة والتحقق قبل الحفظ. ملفات DOC القديمة تحتاج antiword أو LibreOffice، وPDF الممسوح يحتاج OCR أولاً.
- لا تُكتب أي سجلات إذا احتوت المعاينة على أخطاء. لا يتم اختلاق أو استنتاج أي تربص سابق؛ لا يُضاف إلا ما هو مذكور صراحة في الملف.
- احتفظ بنسخة احتياطية قبل الاستيراد، وراجع الأسماء والسنوات والفترات قبل التأكيد.

ملاحظة: هذه نسخة تجريبية محلية للمراجعة، وليست نظاماً طبياً معتمداً بعد. اختبرها وراجع البيانات والقواعد قبل استعمالها في توزيع رسمي. احتفظ بنسخة احتياطية دورية.
